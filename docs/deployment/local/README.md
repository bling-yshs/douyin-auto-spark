# 本地运行

本地运行适合调试脚本或手动执行一次续火任务。

## 1️⃣ 准备环境

需要安装：

| 环境 | 版本要求 |
|:---:|:---:|
| Node.js | 20+ |
| pnpm | 11 |

## 2️⃣ 安装依赖

在项目根目录执行：

```bash
pnpm install
```

## 3️⃣ 配置环境变量

复制 `.env.example` 为 `.env`，再按照主页的 [通用配置](../../../README.md#common-config) 填写 Cookie、好友名称和其他配置。

## 4️⃣ 启动项目

```bash
pnpm dev
```
