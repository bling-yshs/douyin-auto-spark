## GitHub Actions 通知改造（renew-fire.yml）
- 需求：FTQQ 通知仅在 secret 配置后启用 + 移植到 Python + 修复换行符，且只改 workflow、不动主程序。
- 用户确认：secret 名称沿用 `FTQQ_SENDKEY`（历史名），不是 FTQQ_KEY。
- 改动：`.github/workflows/renew-fire.yml` 中「发送构建失败/成功通知」两个步骤重写为内联 Python（stdlib urllib，heredoc 注入，无需 pip/安装 Python——playwright jammy 容器自带 python3）。
- gating：`if: ${{ failure() && secrets.FTQQ_SENDKEY != '' }}` / `success() && ...`（step 级 if 支持 secrets 上下文）。

- 安全细节：secret 只通过 env 传入，不直接内插进 run 脚本（防注入）。
- 验证：YAML 解析 + 内嵌 Python ast 语法检查 + 模拟发送（mock urlopen）确认 desp 内容与编码，全部通过。
